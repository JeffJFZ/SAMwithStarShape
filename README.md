# A-Label-Efficient-SAM-Pipeline-with-Feature-Guided-Star-Shape-Priors
We propose a label-efficient automated pipeline that trains only an object detector with bounding-box annotations, keeps Segment Anything Model (SAM) frozen, and uses pixel-level masks only for benchmark evaluation. (Details in our paper, pls see README.md)

Reference:
Shoujun Huang, Junjie Liu, Shousheng Luo, Huafeng Xie, Jing Yuan, Dexing Kong, Jianfeng Zhang. From automatic detection to segmentation: A label-efficient SAM pipeline with feature-guided star-shape priors for breast ultrasound. Biomedical Signal Processing and Control, DOI: .
